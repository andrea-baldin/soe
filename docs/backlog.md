# Backlog

The backlog records ideas without committing them to the public API.

- Object paths and stable node identities
- Schema-driven structural constraints
- Permission and schema capability providers
- Property providers
- Plugin API consuming NodeContext
- Copy and paste
- Search and filtering
- Alternate renderers
- Custom value editors
- Localization and theming
- Inspection of property descriptors, symbols, maps, and sets

An item moves from this list only when it is needed by the current milestone,
fits the manifesto, and cannot be expressed cleanly by existing concepts.
