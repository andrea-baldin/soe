# SOE 0.3.0

SOE 0.3.0 turns schema knowledge into a complete editing workflow while
preserving the zero-configuration component:

```svelte
<ObjectEditor bind:value />
```

## Highlights

- Compose general type rules with path, predicate, tuple, and explicit-field
  knowledge.
- Report errors and warnings with custom messages, stable codes, and multiple
  diagnostics per field.
- Run cancellable async validation and merge server diagnostics.
- Guide users toward missing fields, defaults, enum choices, and array
  templates.
- Search by path, value, type, or validation state and preview an atomic,
  capability-safe replace-all operation.

## Compatibility

The `0.2.x` zero-configuration API, string validators, synchronous validation,
search string overload, schemas, plugins, and custom value editors remain
supported. New behavior is opt-in through additional schema knowledge or the
collapsed advanced search interface.

Both packages must be upgraded together:

```sh
pnpm add @andreabaldin/soe-svelte@0.3.0
```

`@andreabaldin/soe-svelte` installs the matching core package automatically.
